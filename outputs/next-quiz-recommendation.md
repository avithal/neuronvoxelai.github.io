# Next Lead Magnet Recommendation

---

## Title
**"Is Your Model Edge-Ready?" — The Deployment Readiness Assessment**

## Format
Interactive web tool (single-page calculator/scorecard — similar format to the quiz but positioned as a professional diagnostic tool)

## Description
A 10-question interactive assessment where CV engineers input details about their model (architecture, size, target hardware, latency requirements, framework) and receive an instant "Edge Deployment Readiness Score" with a detailed breakdown across 5 dimensions: Model Size Fit, Quantization Compatibility, Hardware-Runtime Match, Inference Latency Projection, and Production Hardening. The output is a shareable scorecard with specific, actionable next steps (e.g., "Your model is 4.2x too large for Jetson Nano — try structured pruning or switch to MobileNetV3").

## Why It Will Outperform the Harry Potter Quiz

1. **Higher purchase intent.** The Sorting Hat quiz is fun but low-intent — it attracts curious engineers. The Deployment Assessment attracts engineers who are *actively trying to ship a model to production* — these are buyers, not browsers. The Scout research scored edge deployment as the #1 opportunity (19/20 composite).

2. **Complementary funnel position.** The quiz captures top-of-funnel (awareness/entertainment). The assessment captures mid-funnel (evaluation/consideration). Together they cover two stages of the buyer journey without cannibalizing each other.

3. **Shareability with professional credibility.** While the quiz gets shared for fun ("lol I'm a Slytherin"), the assessment gets shared for utility ("this tool told me my model needs INT8 quantization before it'll fit on our target hardware"). Utility-sharing has longer shelf life and higher trust signals in technical communities.

4. **Natural upsell to services.** When someone's assessment reveals gaps (e.g., "Your model isn't production-hardened"), the recommended next step is a NeuronVoxel consulting engagement — not a generic course recommendation. This directly maps to the services page pricing tiers.
